- script d’import Wikipédia non destructif et fondé sur Wikidata.

## Important

Une fiche présente dans l’inventaire n’est pas automatiquement considérée comme scientifiquement établie. Le champ `audit_scientifique` indique le niveau réel de vérification. Le statut « initial critique avec références » ne correspond pas à une revue systématique exhaustive.

Les situations non sourcées comme événements historiques sont des exemples pédagogiques fictifs. Elles illustrent un mécanisme sans diagnostiquer automatiquement un biais dans une situation réelle.


## Compatibilité Windows

L’archive conserve le correctif Unicode UTF-8 introduit en v1.2. Supprimer ou renommer toute ancienne extraction affichant des caractères illisibles, puis extraire cette version dans un dossier neuf. Ne pas fusionner les deux dossiers.
